# Commit Conventions (always on)

- Commit messages explain WHY, not WHAT.
- One logical change per commit. No scope creep.
- Conventional style; branches: `feature/`, `fix/`, `chore/`.
- Commit or push only when asked. Branch first if on the default branch.
- When pushing to remote, tell Sameer what was pushed, briefly.

- PRs: title states the change; body explains the why and how to verify it.
